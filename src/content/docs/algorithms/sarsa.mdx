## Intuition & Overview

SARSA is named after the five values each update uses: $(s, a, r, s', a')$. It works like [Q-Learning](/algorithms/q-learning/) with one change. Instead of assuming it will act perfectly from the next state, it uses the action it has actually chosen, mistakes included. That makes it wary of states where a random slip would be costly.

## Mathematical Foundation

The update replaces the maximum with the value of the next action $a'$ drawn from the current policy:

$$
Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma Q(s', a') - Q(s, a) \right]
$$

This estimates $Q^\pi$, the value of the policy being followed, so SARSA is **on-policy**. With a fixed $\varepsilon$, it learns the best behavior given that it will keep exploring. If $\varepsilon$ decays toward zero, it converges to the optimal policy as well.

## Step-by-Step Breakdown

1. Set every $Q(s, a)$ to zero and choose a first action $a$ with an $\varepsilon$-greedy policy.
2. Take $a$, then observe $r$ and $s'$.
3. Choose the next action $a'$ with the same policy.
4. Apply the update using $Q(s', a')$.
5. Set $s \leftarrow s'$ and $a \leftarrow a'$. The agent is committed to $a'$, which is the key difference from Q-Learning.

```python
def sarsa_update(Q, s, a, r, s_next, a_next, done, alpha=0.5, gamma=1.0):
    future = 0.0 if done else Q[s_next][a_next]
    Q[s][a] += alpha * (r + gamma * future - Q[s][a])
```

## Strengths, Limitations & Real-world Trade-offs

**Strengths**

- It accounts for its own exploration, so it earns more reward during training in risky environments.
- Its updates have lower variance than the $\max$-based target in many settings.

**Limitations**

- With fixed exploration, the learned policy is not the optimal one.
- It cannot learn from another policy's data without corrections.
- Like Q-Learning, a table does not scale to large state spaces.

Choose SARSA when mistakes during learning are expensive, such as on a physical robot. Choose Q-Learning when only the final policy matters, such as training in simulation.
