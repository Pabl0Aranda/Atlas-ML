## Intuition & Overview

[Lasso](/algorithms/lasso-regression/) selects <Term id="feature">features</Term> but behaves erratically when they are correlated. [Ridge](/algorithms/ridge-regression/) is stable but keeps everything. Elastic net mixes both penalties, so it can drop features while treating correlated groups more evenly.

## Mathematical Foundation

With mixing ratio $\rho$ between 0 and 1:

$$
\min_w \; \frac{1}{2n} \lVert y - Xw \rVert^2 + \lambda \left( \rho \lVert w \rVert_1 + \frac{1 - \rho}{2} \lVert w \rVert_2^2 \right)
$$

Setting $\rho = 1$ gives lasso, and $\rho = 0$ gives ridge. Each coordinate update combines both effects, a threshold from the L1 part and extra shrinkage from the L2 part:

$$
w_j = \frac{S(c_j, \lambda \rho)}{z_j + \lambda (1 - \rho)}
$$

## Step-by-Step Breakdown

1. Choose $\lambda$ and $\rho$, usually by [cross-validation](/validation/cross-validation/).
2. Start at zero.
3. Apply the coordinate update to each coefficient.
4. Repeat until the coefficients stop changing.

## Strengths, Limitations & Real-world Trade-offs

**Strengths**

- It combines feature selection with stability on correlated features.
- It can keep more than $n$ features, unlike lasso.

**Limitations**

- There are two <Term id="hyperparameter">hyperparameters</Term> to tune instead of one.
- Like lasso, it adds bias to the coefficients it keeps.
- Features must be scaled.
