## Intuition & Overview

Despite the name, logistic regression is a classifier. It computes a linear score, then squashes it into a probability between 0 and 1. It is the standard baseline for classification, because it is fast, its weights can be interpreted, and its probabilities are often well behaved.

## Mathematical Foundation

The model passes a linear score through the sigmoid function:

$$
P(y = 1 \mid x) = \sigma(w^\top x) = \frac{1}{1 + e^{-w^\top x}}
$$

Equivalently, the log-odds are linear: $\log \frac{p}{1 - p} = w^\top x$. So each weight says how much one unit of a feature changes the log-odds. Training maximizes the likelihood, which means minimizing the log loss:

$$
L(w) = -\frac{1}{n} \sum_i \left[ y_i \log p_i + (1 - y_i) \log (1 - p_i) \right] + \frac{\lambda}{2} \lVert w \rVert^2
$$

The gradient has a simple form, and the loss is convex, so there are no bad local minima:

$$
\nabla L(w) = \frac{1}{n} \sum_i (p_i - y_i)\, x_i + \lambda w
$$

## Step-by-Step Breakdown

1. Start with all weights at zero, which gives every point probability 0.5.
2. Compute each probability and its error $p_i - y_i$.
3. Take a gradient step.
4. Repeat until the loss settles.
5. Predict class 1 when the probability passes a [threshold you choose](/testing/classification-metrics/).

## Strengths, Limitations & Real-world Trade-offs

**Strengths**

- Interpretable, fast and hard to beat as a baseline.
- It outputs probabilities directly.

**Limitations**

- The boundary is linear unless you engineer features.
- Correlated features make individual weights unreliable.
- Separable data needs regularization, or the weights grow without limit.
