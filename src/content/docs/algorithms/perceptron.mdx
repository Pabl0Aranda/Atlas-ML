## Intuition & Overview

The perceptron, introduced by Frank Rosenblatt in 1958, sums weighted inputs and fires if the total crosses a threshold. When it gets a sample wrong, it nudges the boundary toward that sample. When it is right, it does nothing.

## Mathematical Foundation

The prediction is a step function of a linear score:

$$
\hat{y} = \mathbb{1}[w^\top x + b > 0]
$$

For each sample, with targets $y \in \{0, 1\}$, the update is:

$$
w \leftarrow w + \alpha (y - \hat{y})\, x, \qquad b \leftarrow b + \alpha (y - \hat{y})
$$

The perceptron convergence theorem guarantees a finite number of mistakes when the classes are linearly separable. If they are not, the weights never settle.

## Step-by-Step Breakdown

1. Start with small weights.
2. Visit each sample and compute $\hat{y}$.
3. If it is wrong, apply the update.
4. Stop after an epoch with no mistakes.

## Strengths, Limitations & Real-world Trade-offs

**Strengths**

- Tiny, fast and naturally online: it learns from one sample at a time.
- Comes with a clean convergence guarantee on separable data.

**Limitations**

- It only draws linear boundaries.
- Any separating line satisfies it, so the margin may be poor. Compare the [SVM](/algorithms/svm/).
- It produces no probabilities and oscillates on noisy data.
