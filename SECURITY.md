# Security Policy

Atlas ML is a static website. It has no backend, no database and no user accounts, and it doesn't collect personal data. Everything runs in your browser, which limits what can go wrong, but issues are still possible.

## Supported versions

Only the latest version, running at <https://pabl0aranda.github.io/Atlas-ML/>, receives fixes.

## Reporting a vulnerability

Please don't open a public issue for a security problem. Instead, [report it privately](https://github.com/Pabl0Aranda/Atlas-ML/security/advisories/new) through GitHub.

Include what you found, the steps to reproduce it, and the effect it could have. Reports are reviewed as soon as possible, and you'll be told how yours is being handled.

## What's useful to report

- Script injection, such as through a crafted share link.
- A vulnerable dependency that affects the published site.
- Secrets or private data in the repository.

Bugs that don't affect security are better reported as a [normal issue](https://github.com/Pabl0Aranda/Atlas-ML/issues/new/choose).
